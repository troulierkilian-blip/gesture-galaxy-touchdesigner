# v1.0.0 验收摘要

此摘要由原始本机结果整理，未公开相机画面、原始手部坐标、个人路径或浏览器调试数据。

## 历史性能

测试日期：2026-10-23。宿主：TouchDesigner 2025.33230 Non-Commercial；显卡：RTX 3060 Laptop，6GB VRAM；相机：内置摄像头，1280×720、30 FPS。

| 项目 | 实测 |
| --- | --- |
| 输出 | 1280×720 |
| 星点数量 | 20,000 |
| 体积星云 | 640×360，16 步 |
| 辉光 / 拖尾 | 0.32 / 0.08 |
| 连续运行 | 600.02 秒，600 个逐秒样本 |
| 平均 / 中位 / 最低帧率 | 58.97 / 60.00 / 52.17 FPS |
| 相机更新、实际渲染帧推进、配置稳定性 | 通过 |

FPS 是完整 TouchDesigner 帧循环的测量值。此次测试未降低画质，但不同硬件、相机和后台负载可能产生不同结果。
